Fines (<63 µm)

The mud (clay + silt) fraction of each sample, derived from grain-size data

The fraction of a sediment finer than 63 µm (clay plus silt, the “mud” fraction) is a key descriptor: it governs how much surface area is available to bind trace elements, and it is the usual basis for comparing contaminant levels between samples. This page derives a single per-sample value, subsample.fines_lt63 (a percentage), from each source’s grain-size measurements, and records in fines_basis how it was obtained.

Every source with grain-size contributes (all but 4Demon, which carries no grain-size). The value is taken from the corrected standardised value value_std_corr (grain size to %), so mixed reporting units (%, g/kg) are handled uniformly and the grain-size curves repaired in the correction step (see below) are used.

1. How the fines fraction is derived

Each source encodes grain-size differently, and the parameter names do not mean the same thing across sources, so the meaning of every code was checked against the pilot parameter definitions before use.

Source Code used fines_lt63 fines_basis
Mareano Clay + Silt bins Clay (<2 µm) + Silt (2 to 63 µm) sum_bins
Vannmiljø FINS, complement, or clay+silt FINS, else 100 minus GSMF_63, else GSMF2 + GSMF2_63 fins / gsmf_63_complement / clay_silt_sum
ICES-DOME GSMF63 on a bulk matrix Cumulative <63 µm on SEDtot, else SED2000 gsmf63_sedtot / gsmf63_sed2000
MUDAB GSMF63 on a bulk matrix Cumulative <63 µm on SEDtot, else SED2000 gsmf63_sedtot / gsmf63_sed2000

Two points that the derivation has to get right:

  • The names can be reversed. In ICES-DOME and MUDAB, GSMF63 is the mass fraction finer than 63 µm (silt and clay). In Vannmiljø the similar-looking GSMF_63 is the opposite: “Particle fraction >63 µm” (sand and coarser). So Vannmiljø’s fines come from FINS, and where only GSMF_63 exists the fines are 100 minus GSMF_63.
  • The fraction is relative to the matrix. A cumulative GSMF63 is the <63 µm share of whatever fraction it was measured on (see the Sample Fraction page). It is taken from the whole sample (SEDtot) first, and otherwise from SED2000 / SED1000 (the <2 mm / <1 mm material). Values measured on an already-fine fraction (which would be near 100 %) are not used. The SED2000 based values come with the gravel caveat below.
WarningThe SED2000 based fines assume negligible gravel

A SED2000 value is the <63 µm share of the <2 mm material, not of the whole sample. Converting it to a whole-sample value would need the gravel (>2 mm) proportion, but these ~2,356 subsamples (2,346 ICES-DOME, 10 MUDAB) were analysed only on the sieved <2 mm fraction, so their gravel was never measured and cannot be reconciled. They are therefore taken as whole-sample fines assuming gravel is negligible (true for open marine sediment, not for gravelly or coastal sites). They carry fines_basis = 'gsmf63_sed2000', so they can be identified, down-weighted, or dropped downstream. The gsmf63_sedtot values are genuine whole-sample fines and need no such caveat.

2. Correcting noisy grain-size curves

Much of the grain-size data outside Mareano is noisy: many curves are internally consistent (a monotone cumulative distribution) but scaled wrong, so a value that should sit near 100 % is reported as thousands of percent, with every code in the sample inflated by the same factor. A separate correction step handles this before the fines are derived, writing a corrected value (value_std_corr) and a marker (gs_corr) on each measurement:

  • ICES-DOME and MUDAB renormalise each over-scaled, still-monotone curve so its coarsest cutoff (the total, near the <2 mm fraction) reads 100 % (gs_corr = 'renorm'). This recovers the affected samples for the fines below.
  • Vannmiljø has only a handful of isolated bad values (and its codes mean “>n µm”, so the curve renormalisation does not apply): these were manually reviewed against the raw data, found incorrect, and flagged gs_corr = 'invalid' (their standardised value nulled) for removal in the clean stage.
Source Renormed Invalid
Vannmiljø 0 22
ICES-DOME 1,147 0
MUDAB 1,068 0

Mareano needs no correction (its named-bin grain-size is already clean), so it has no gs_corr column and its fines read the uncorrected value.

Coverage is partial by design: a subsample contributes only if it has a usable <63 µm measurement. Implausible values (a cumulative mass fraction outside 0 to 100 %, about 1 % of the grain-size rows) are left out rather than corrected here.

Note

fines_lt63 is a reusable derived quantity, not a flag: nothing is deleted. For Vannmiljø, samples with neither direct code fall back to the clay + silt sum (GSMF2 + GSMF2_63), the same construction as Mareano. The equivalent bin route for ICES-DOME and MUDAB reaches only <60 µm (a different cutoff) and was left out. The SED2000 gravel adjustment cannot be computed (no whole-sample grain-size exists for those samples), so it is handled by the documented assumption above. The Vannmiljø values the correction could not repair have now been reviewed and flagged invalid (removed in the clean stage), so no grain-size items remain open.
