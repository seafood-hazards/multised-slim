Unit Conversion & Range Check

Standardising values to a common unit, then flagging implausible concentrations

The five sources report the same measurements in different units: mg/kg, µg/kg, %, g/kg, and so on. Before implausible values can be flagged consistently, every value is first converted to a common unit, and the standardised chemistry values are then compared against a plausible range per element. Both are additive columns on measurement; nothing is deleted here.

1. Unit conversion

Each measurement gets a standardised value value_std and its unit unit_std, assigned by measurand rather than by the raw unit:

  • Chemistry: the 7 target elements, the Fe/Al normalisers, and organic carbon (CORG / TOC / TOC63) → mg/kg dry weight.
  • Grain-size composition → % (a mass/volume fraction). There is no length/µm grain-size in the data, so every grain-size value is a fraction and standardises to %.

The conversion goes through the mass fraction value / denom, where denom is “100 % of the sample mass” expressed in the original unit, then scales to the target unit’s full scale (1,000,000 for mg/kg, 100 for %).

Where a source supplies a QC-corrected value, that is the value standardised here: 4Demon’s corrected_value (which its metadata recommends for analysis) carries scale-error fixes and below-detection substitutions, while the raw value is kept as provenance. This corrected a batch of 4Demon iron values reported about 10 times too high.

Measurand Standard unit Example conversion
Targets (Co, Cu, I, Mn, Mo, Se, Zn) mg/kg 9.8 % Cu → 98,000 mg/kg
Normalisers (Fe, Al) mg/kg 3.31 % Al → 33,100 mg/kg
Organic carbon (CORG / TOC / TOC63) mg/kg 85 g/kg C → 85,000 mg/kg
Grain-size composition % 180 g/kg → 18 %

2. Plausible range check

The standardised value_std (mg/kg) of every chemistry measurement is compared against a per-element plausible range. A value below the minimum is flagged below_min, above the maximum above_max; everything else, including grain-size (unbounded) and below-LOQ readings (a limit, not a value), stays unflagged.

Warning

These bounds are a draft, deliberately generous: they target clearly implausible values (both impossibly high and impossibly low), not strict geochemical limits, and are still to be reviewed with domain experts.
