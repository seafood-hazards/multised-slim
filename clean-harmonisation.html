Harmonisation

Uniform symbols, units and depths across the five sources

Step 1 puts every source into one format, using the ICES-DOME vocabulary. Values are not changed: the original value and unit are kept, alongside a standardised value in a common unit.

1. Symbols

Chemistry symbols are unified to the ICES names: the seven targets, the Fe/Al normalisers, and organic carbon CORG (Mareano/Vannmiljø TOC maps to CORG; Vannmiljø’s TOC63, carbon on the <63 µm fraction, is kept separate). Case is folded (Fe becomes FE). The chemistry symbols now present per source:

Source Symbols
Mareano AL, CO, CORG, CU, FE, MN, MO, SE, ZN
Vannmiljø AL, CO, CORG, CU, FE, MN, MO, SE, TOC63, ZN
ICES-DOME AL, CO, CORG, CU, FE, I, MN, MO, SE, ZN
MUDAB AL, CO, CORG, CU, FE, MN, MO, SE, ZN
4Demon AL, CU, FE, ZN

2. Units

The original unit is retained (renamed to the ICES form: micro sign to u, and Vannmiljø’s dw / C suffixes stripped), and every measurement also carries a standardised value_std in mg/kg (unit_std), converted via its mass basis. Original chemistry units still present:

Source Original units
Mareano mg/kg, wt.%
Vannmiljø g/kg, mg/kg, ug/kg
ICES-DOME %, g/kg, mg/kg, ug/g, ug/kg
MUDAB %, g/kg, mg/kg
4Demon ug/g

3. Depth

Sediment depth intervals are all converted to centimetres. The sources stored depth differently: ICES-DOME in metres (multiplied by 100), the others already in cm. Vannmiljø’s corrupt depths (beyond a plausible core length, or inverted) were set to unknown.

Source Min depth (cm) Max depth (cm) Depth unknown
Mareano 0 49 0
Vannmiljø 0 300 221
ICES-DOME 0 200 0
MUDAB 0 200 0
4Demon 0 20 0

4. Gear and detection limits

sampling_tool and method are carried in the ICES form where the source already uses ICES-style codes (Mareano, ICES-DOME, MUDAB, 4Demon). Vannmiljø records ISO sampling standards that do not map to ICES gear, so they are left as-is. Detection and quantification limits (lod / loq) are kept on the method table with their reporting unit (limit_unit); Mareano’s single lld becomes lod, and 4Demon carries no numeric limits.

Source Methods With LOD With LOQ
Mareano 23 23 0
Vannmiljø 446 135 339
ICES-DOME 1,314 849 272
MUDAB 423 225 143
4Demon 38 0 0
